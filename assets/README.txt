DHIVIYAN & MEENALOSHINI — WEBSITE ASSETS

These assets are prepared for the animated wedding invitation.

IMPORTANT:
- The *_sheet.png files are the original multi-element sheets.
- The individual/ folders contain automatically extracted transparent pieces.
- Use the individual pieces in JavaScript/CSS so each leaf, butterfly,
  wisteria cluster, or petal can be positioned and animated separately.

Recommended website structure:

assets/
  flowers/
  leaves/individual/
  stems/
  wisteria/individual/wisteria-long/
  wisteria/individual/wisteria-medium/
  wisteria/individual/wisteria-short/
  butterflies/individual/
  petals/individual/

Next, these individual assets can be loaded by JavaScript and given
different positions, sizes, rotations, opacity, animation duration,
and animation delays.
